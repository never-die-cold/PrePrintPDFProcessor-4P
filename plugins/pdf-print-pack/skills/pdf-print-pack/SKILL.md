# PDF 省纸打印（pdf-print-pack）

把“要打印的 PDF 太费纸、太费墨、太大、排版不适合读”这类需求，变成一条命令或一次重排。
核心算术：**原样单面打印 P 页占 P 张纸；N 合 1 + 双面打印只占 ⌈P/2N⌉ 张纸**（3 合 1 双面 = 每张纸 6 页）。

## 先选路径

| 用户想要 | 走哪条 | 成本 |
| --- | --- | --- |
| “帮我把这个 PDF 省纸打印 / 3 合 1 / 压缩一下 / 太费纸” | **A. 一键拼版**（`pack.py`） | 一条命令，秒级，不改内容 |
| “把课件整理成能通读的讲义 / 浓缩 / 速查表” | **B. 重排讲义**（HTML→PDF） | 需逐页读源文件并改写，产出最费纸也最省（4-6 逻辑页/张） |
| 考前 2 页极简速查 | **C. 速查变体** | 介于两者之间 |

不要用 A 去应付“整理成讲义”的请求，也不要用 B 去应付“只是想让打印别那么费纸”的请求。

## 路径 A：一键拼版

```bash
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 输入.pdf
```

默认行为（auto）已经是最常用组合，先跑它，看报告再决定要不要调参：

- **自动选排版**：横向课件（宽高比 ≥1.15）→ 纵向 A4 竖排 3 格（3 合 1，双面 6 页/张，与仓库 `数电课件_3合1_讲义版.pdf` 一致）；纵向文档 → 横向 A4 并排 2 格（2 合 1，双面 4 页/张，与仓库 `*_学习讲义_2合1省纸打印版.pdf` 一致）。
- **自动裁白边**：内容外接框比页面省 6% 以上才裁，裁后内容放大铺满格子（整份文件统一矩形，各页缩放一致）。
- **自动页标**：每格左上角 `L1-01…`（前缀从文件名取，多个文件各自编号：第二个文件从 `L2-01` 起；`--label 前缀` 可覆盖，`--label none` 关）。
- **自动页脚**：多面输出时加 `第 i 张 / 共 N 张`。
- **自动瘦身**：图片降采样到 ≤200dpi、JPEG 质量 75 重编码，**只在体积变小才采用**，不影响矢量文字清晰度。

### 常用配方

```bash
# 课件（自动判为 3 合 1，纵向 A4，每张纸 6 页）
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 课件.pdf

# 更狠的 6 合 1 + 灰度省墨 + 补偶（双面不打乱）
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 课件.pdf --nup 6 --gray --pad-duplex

# 多文件按章合并（自动自然排序：第2章在上、第10章在下；--no-sort 保持命令行顺序）
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 第*.pdf -o 课程_省纸打印版.pdf --nup 3

# 小册子：对折成 A5、骑马钉顺序，双面长边翻转后沿中线装订
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 讲义.pdf --booklet

# 扫描件/图片型课件：光栅灰度，体积可再降一半以上
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 扫描.pdf --gray-raster --dpi 150 --quality 60

# 只印重点：取第 1-10 页与 20 页起
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 书.pdf --pages 1-10,20-

# 扫描件/习题集：保留原大、省墨、双面不乱
python "${ZCODE_SKILL_DIR}/scripts/pack.py" 扫描.pdf --no-trim --gray --pad-duplex
```

### 参数速查

| 参数 | 说明 |
| --- | --- |
| `--nup auto\|2\|3\|4\|6\|8\|9\|12\|16` | 每张纸拼几页；也接受 `3in1` 写法；默认 `auto` |
| `--grid 2x2` | 手动网格（覆盖 `--nup`） |
| `--paper a4\|a3\|a5\|letter` / `--margin` / `--gap` | 纸张与边距（mm，默认 8/3） |
| `--frame none\|thin\|box` / `--mark` | 格边框 / 格间虚线裁切线 |
| `--label auto\|none\|前缀` / `--footer auto\|none\|文字` | 每格页标 / 页脚 |
| `--cost 0.1` | 每张纸单价（元）：报告直接给出“本次省 X 元” |
| `--gutter 10` / `--mirror` | 装订线：装订侧留 10mm；`--mirror` 让背面镜像（双面装订用）；小册子自动朝中缝 |
| `--gray` | 转灰度（矢量级转换，文字仍清晰可搜索），省彩色墨 |
| `--gray-raster` | 光栅灰度：整页转灰度 JPEG，体积/墨量最省；文字不再可搜索，适合扫描件与图片型课件 |
| `--enhance` | 扫描件清理：去底灰 + 对比伸展（有 Pillow 时加轻度去噪），省墨大头 |
| `--binarize` | 二值化纯黑白（Otsu 阈值，隐含 --enhance），纯文字扫描件最省墨 |
| `--deskew` | 自动校正扫描倾斜（行投影法；需 `pip install pillow`，建议与 --enhance 同用） |
| `--pad-duplex` | 补空白面，总面数变偶数，双面打印不变错位 |
| `--rotate-back` | 打印机只能在**短边**翻转时加；长边翻转不要加 |
| `--booklet` | 对折骑马钉拼版（适合竖版文档；已拼过版的 2 合 1 材料不要再用） |
| `--trim-force` / `--no-trim` / `--trim-threshold 0.94` | 白边裁剪控制 |
| `--pages 1-5,8,11-` / `--skip-blank` | 选页 / 跳空白页 |
| `--outline auto\|none\|数字` | 书签目录：默认 auto（源有目录就保留，点击跳到对应张/格），数字=保留到第几级 |
| `--page-labels auto\|none` | 输出页标签：默认 auto，每张纸标注它是从源文档第几页开始的 |
| `--quality 75 --dpi 200 --optimize auto\|off` | 瘦身参数；`off` 可关 |
| `--password` / `--force` / `--no-sort` / `--json` | 加密 PDF / 覆盖保护 / 排序 / 机器可读报告 |

### 输出与安全约定

- 输出默认 `<输入名>_省纸打印版.pdf`（多文件在第一个文件的目录里叫 `合并_省纸打印版.pdf`）。
- **绝不修改输入**；输出已存在且不是本工具生成的 → 拒绝覆盖并要求 `--force` 或换 `-o`。
- 报告里的省纸账以**原样单面**为基准（人们实际最常这么打），同时给出“若原样也双面”的对比；向用户解释时直接用报告原话，例如“原样单面 79 张 → 省纸版双面 10 张（省 87%）”。

## 路径 B：课件重排成 2 合 1 浓缩讲义

目标产物与仓库既有文件同规格：A4 横向、每张纸并排 2 个 A5 逻辑页、双面后每张纸 4 逻辑页、正文 7.5pt、页脚“第 N 页”连续编号、封面 + 目录 + 正文 + 易错清单。
**版式范例（照抄它）**：`文档处理打印处/信号与系统/信号与系统_学习讲义_2合1.html`；主题 CSS 与骨架在 `${ZCODE_SKILL_DIR}/assets/`。

流程：

1. **通读源课件**：`pymupdf` 按页抽文本（`page.get_text("text")`），分批读完全部讲稿；同时看每页渲染图，判断哪些图必须保留（公式截图、波形、电路），哪些能用一句话+表格替代。
2. **先列大纲再写字**：按“章 → 小节 → 要点”列提纲，覆盖原课件的全部定义、公式、性质、定理、判据与例题套路；标注易错点与课件一带而过的理由。
3. **规划逻辑页**：每逻辑页正文区高 172mm ≈ 7.5pt 下 45-60 行；一节通常 1-3 个逻辑页。目录页码 = 逻辑页序号（连续编号，跨 sheet 不重排）。
4. **写 HTML**：复制 `assets/handout-skeleton.html` 起手（已含封面、目录、正文页三件套与全部类），主题样式内联；表格用 `.tb`，必记结论用 `.box`，公式用 `<span class="m">`，上下标用 `<sup>/<sub>`。
5. **转 PDF**：
   ```bash
   python "${ZCODE_SKILL_DIR}/scripts/html2pdf.py" 讲义.html -o 课程名_学习讲义_2合1省纸打印版.pdf
   ```
6. **必须目视验收**：渲染各页 PNG 检查——正文是否溢出 `.bd` 被裁、表格是否串行、页码/目录是否对上、每张纸上两个逻辑页是否都完整。用 `documents:visual-judge` 子代理做验收，别自己顺便看。
7. **命名与落盘**：`<课程名>_学习讲义_2合1省纸打印版.pdf` 与同名 `.html` 一起放在源课件目录（与仓库既有做法一致），并在封面/说明页写明“4 逻辑页/张、按第 N 页顺序阅读”。

内容压缩原则（这不只是排版，是改写）：

- **压缩推导过程与动画，不压缩结论**：定义、公式、定理、判据、取值范围、适用条件、易错点必须逐条保留。
- 对比类内容一律表格化（`.tb` + `.cap` 表题）；判据/路线汇总用 `.box`。
- 加“符号约定”“常见混淆 n 组概念”“打印说明”三个固定模块；结尾放“公式速查 + 易错清单”。
- 每节标题带页码锚点（`<h1>第 1 章　绪论<span>4</span></h1>` 右侧小字=页码）。

## 路径 C：知识点压缩速查（2 页变体）

考前速查版：`@page { size: 210mm 297mm; margin: 0 }`，正文两栏（`column-count:2; column-gap:6mm`），条目一行一条、无推导；
每章一个色条小标题（参考 `数电知识点压缩速查_打印版.pdf` 的风格）。仍用 `html2pdf.py` 转 PDF，导出前确认正好 2 页。

## 打印设置建议（写进交付说明）

A4、缩放选 **100% / 实际大小**、关闭“适合页面/适应纸张”；
双面选**长边翻转**（短边翻转的机器：拼版时加 `--rotate-back`）；
省墨档/灰度开；文件小、页数少，注意开启“按实际尺寸”避免打印机二次缩放。

## 环境与排错

- Python 用 `python`（Windows）或 `python3`；缺库：`pip install pymupdf`。
- 中文字体无需外部文件（内置 `china-s` 用于页标/页脚）。
- 找不到 Edge/Chrome：`html2pdf.py --browser <路径>` 或设 `PDFPP_BROWSER`。
- 加密 PDF：`--password`；打开失败会明确报错，不要静默跳过文件。
- 输出被拒绝：同名文件不是本工具生成的，`--force` 或换 `-o`。
- 面数不是偶数又不是 `--pad-duplex`：报告里会提示。

### 速度参考（本机实测，Windows + SSD）

| 规模 | 默认 | `--fast` |
| --- | --- | --- |
| 单个课件 30-90 页 | 5-15 秒 | 2-5 秒 |
| 11 份整册 741 页 / 100 MB | 约 1 分 50 秒 | 约 2 分钟 |

默认会做字体子集化与图片瘦身（省体积）；`--fast` 跳过它们换速度。默认存盘用 `garbage=2`；
`--compact` 开跨对象深度去重，约再省 10% 体积，但大文件多花 1-2 分钟。批量整册建议默认即可，
先给用户报“页数 → 纸张数”的省纸结论，不要卡在体积优化上。
